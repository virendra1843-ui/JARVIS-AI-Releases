# JARVIS AI – Installer Error Codes

## Overview
JARVIS AI is an AI-powered desktop assistant developed by TechVyom.

This document provides information about installer error codes.

## Installation Return Codes

| Return Code | Description |
|---|---|
| 0 | Installation completed successfully |
| 1 | General installation failure |
| 2 | Installation cancelled by user |
| 3 | Application already exists |
| 4 | Insufficient disk space |
| 5 | Installation requires administrator privileges |
| 6 | Network connection failure |
| 7 | Installation requires system restart |

## Troubleshooting
If installation fails:
- Check your internet connection.
- Ensure sufficient disk space.
- Run the installer with appropriate permissions.
- Restart Windows if required.
